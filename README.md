# Gita Brain — V0

A grounded AI reflection engine based on the Bhagavad Gita.

## Principles
1. Scripture, translations, commentaries, and application are separate layers.
2. Never invent or fabricate a verse, citation, translation, or commentary.
3. Retrieved source material must be available to the reasoner before it makes scriptural claims.
4. The system provides reflection, not divine communication or professional therapy.
5. Every redistributable text source must carry provenance and license metadata.

## Current status
This is the initial scaffold. The 18-chapter/700-verse index, concept taxonomy,
situation taxonomy, prompts, safety policy, and evaluation framework are included.
The verse corpus must be ingested and validated from approved sources before production use.
