# V0.5 — Semantic Concept Layer

The original keyword candidate generator was too noisy and too sparse.
V0.5 introduces:
- a controlled 39-concept ontology
- relationship labels: DIRECT / INFERRED / CONTEXTUAL
- stronger use of source theme metadata
- guarded lexical evidence
- high-precision combination rules
- explicit review states

Run:

```bash
python scripts/build_semantic_candidates.py
python scripts/inspect_candidates.py
```

The generated `verse_concept_candidates_v2.json` is still candidate data.
It is not production truth.
