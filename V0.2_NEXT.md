# Gita Brain V0.2

## What is locked
- 18 chapters
- 700-verse application target
- source provenance
- source-preserving ingestion
- no silent deletion/merging
- explicit Chapter 13 canonicalization gate

## Run locally
```bash
python scripts/ingest.py
python scripts/canonicalize.py
```

The first command downloads the selected source into `data/raw/` and creates
`data/processed/source_verses.json`.

The second command intentionally stops until Chapter 13 has a reviewed mapping.

## Why the stop exists
The selected machine-readable source reports 701 records because its Chapter 13
numbering convention contains 35 numbered records. Other Gita sources also publish
Chapter 13 as 35 verses, while the project's initial target was the common 700-verse
count. We will not solve this by guessing.

## Next engineering milestone
1. Resolve the Chapter 13 edition mapping.
2. Produce `data/processed/verses.json`.
3. Add automated schema + count validation.
4. Build verse → concept annotations.
5. Build hybrid retrieval.
