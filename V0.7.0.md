# V0.7.0 — Situation & Answer Engine foundation

V0.7 adds the intelligence pipeline before an LLM renderer:
1. mood + free-form text
2. situation inference
3. concept construction
4. V0.6.2 situation-aware retrieval
5. structured answer plan

The answer plan intentionally contains no generated scripture prose. The final
LLM layer should receive the user's input plus the retrieved evidence and
answer policy, then render the response.

Commands:
```powershell
python scripts/test_v070.py
python scripts/build_answer_plan.py --mood anxious --text "I'm scared my business will fail."
```

This is a foundation, not a claim that keyword matching alone is sufficient
for production. The next iteration should add an LLM-backed structured
situation classifier and a grounded response renderer with adversarial tests.
