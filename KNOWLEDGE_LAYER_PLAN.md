# Knowledge Layer Plan — V0.3

We now have a canonical 700-verse source strategy.

## Layer 1 — Scripture
- `sanskrit`
- `transliteration`
- chapter/verse
- speaker
- provenance

Immutable after review.

## Layer 2 — Source interpretations
Kept separately by school/commentator. Never collapsed into a single truth field.

## Layer 3 — Application/enrichment
Theme memberships, primary meaning, everyday applications, and our own situation mappings.

## Layer 4 — AI reasoning
The model receives retrieved Layer 1 + selected Layer 2/3 evidence and generates an application.

### Critical rule
The model must never treat Layer 3 as if it were Layer 1.
