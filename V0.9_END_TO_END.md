# V0.9 — First Real Answer Engine

V0.9 turns the existing retrieval/evidence pipeline into an end-to-end
answer generator.

## 1. Configure the server-side LLM key

PowerShell:
```powershell
$env:OPENAI_API_KEY="YOUR_SERVER_SIDE_KEY"
$env:GITA_BRAIN_MODEL="gpt-5.6"
```

Do NOT put the key in Android.

## 2. Test the deterministic grounding guard

```powershell
python scripts/test_v090.py
```

This does not require an API key.

## 3. Generate the first real answer

```powershell
python scripts/ask_gita.py --mood anxious --text "I've worked on my business for two years and I'm terrified that all of it will fail. What if I lose everything?"
```

JSON mode:

```powershell
python scripts/ask_gita.py --mood anxious --text "I've worked on my business for two years and I'm terrified that all of it will fail." --json
```

## What V0.9 adds

- Real LLM answer generation from the grounded evidence pack.
- CLI for asking Gita Brain.
- Server-side API key boundary.
- Verse-reference grounding guard.
- Structured response metadata.
- Deterministic tests that run without an LLM key.

The answer should explain the retrieved Gita evidence, distinguish scripture
from modern application, and avoid inventing verses or quotations.

The next milestone after V0.9 is the Android client + production backend.
