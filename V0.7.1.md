# V0.7.1 — Semantic input understanding

Changes:
- Expanded natural-language situation aliases.
- Added concept-level text cues.
- Analyzer now emits concept evidence.
- Situation confidence now reflects converging evidence.
- Selected mood remains explicit UI context.
- Added multiple realistic jealousy/comparison tests.
- Existing V0.6.2 retrieval remains the evidence-ranking layer.

Run:
```powershell
python scripts/test_v071.py
python scripts/analyze_input.py --mood jealous --text "Everyone around me is succeeding and I feel jealous and behind."
python scripts/build_answer_plan.py --mood jealous --text "Why does everyone else have what I want? I keep comparing myself to them."
```

The LLM is still intentionally not part of this release. The next stage is a
grounded answer renderer after this classifier/retriever passes the expanded
test suite.
