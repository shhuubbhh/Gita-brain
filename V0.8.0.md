# V0.8.0 — Grounded Answer Engine

V0.8 introduces the boundary between deterministic Gita retrieval and the
future LLM response renderer.

Pipeline:
user input -> V0.7 situation/concepts -> V0.6.2 retrieval -> evidence pack ->
strict LLM prompt -> answer -> output validation.

Important design choice:
The LLM is NOT given authority to invent scripture. Retrieved corpus evidence
is the only source of scriptural claims.

Commands:
```powershell
python scripts/test_v080.py

python scripts/build_evidence_pack.py --mood anxious --text "I'm scared my business will fail."

python scripts/build_evidence_pack.py --mood anxious --text "I'm scared my business will fail." --out evidence.json

python scripts/build_llm_prompt.py --evidence evidence.json --out prompt.txt
```

To validate an LLM answer saved as answer.txt:
```powershell
python scripts/validate_llm_output.py --answer answer.txt --evidence evidence.json
```

No API key is embedded. The next integration can target the LLM provider used
by the Android/backend stack while keeping this grounding boundary intact.
