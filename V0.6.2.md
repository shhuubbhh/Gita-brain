# V0.6.2 — Situation-aware retrieval

V0.6.2 improves ranking by making concept importance situation-specific.

Key principle:
- A shared concept such as `attachment` should not dominate every situation.
- Situation-central concepts receive higher ranking weight.
- DIRECT / INFERRED / CONTEXTUAL evidence strength remains intact.
- The canonical 700-verse corpus is unchanged.
- V2/V3 evidence is preserved.

Commands:
```powershell
python scripts/benchmark_retrieval.py
python scripts/compare_situation_ranking.py --situation grief
python scripts/compare_situation_ranking.py --situation fear_of_failure
```

The weights are retrieval priorities, not theological claims. They should be
reviewed and expanded as the benchmark suite grows.
