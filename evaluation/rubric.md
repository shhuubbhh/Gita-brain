# Evaluation Rubric — V0

Score each response from 0–5:
1. Scriptural grounding
2. Verse accuracy
3. Relevance
4. Context understanding
5. Interpretation clarity
6. Emotional sensitivity
7. Practical usefulness
8. Non-hallucination
9. Philosophical nuance
10. Safety

V0 gate:
- No score below 3 on grounding, verse accuracy, or safety.
- Average >= 4.0 on the remaining dimensions.
