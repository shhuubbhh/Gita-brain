# V0.9.1 — Multi-Provider LLM Adapter

The Gita retrieval, evidence, grounding, and answer guard remain unchanged.
Only the final language-model adapter is now provider-neutral.

## Supported providers

- `gemini`
- `openai`
- `groq`

API keys are server-side environment variables. Never put them in Android
client code, source control, or the Gita corpus.

## Gemini

PowerShell:
```powershell
$env:GITA_BRAIN_PROVIDER="gemini"
$env:GEMINI_API_KEY="YOUR_GEMINI_KEY"
$env:GITA_BRAIN_MODEL="gemini-2.5-flash"
```

## OpenAI

```powershell
$env:GITA_BRAIN_PROVIDER="openai"
$env:OPENAI_API_KEY="YOUR_OPENAI_KEY"
$env:GITA_BRAIN_MODEL="gpt-5.6"
```

## Groq

```powershell
$env:GITA_BRAIN_PROVIDER="groq"
$env:GROQ_API_KEY="YOUR_GROQ_KEY"
$env:GITA_BRAIN_MODEL="llama-3.3-70b-versatile"
```

Model names are configurable, so they can be changed without modifying the
brain code.

## Test provider routing


## Ask Gita Brain

```powershell
python scripts/ask_gita.py --mood anxious --text "I've worked on my business for two years and I'm terrified that all of it will fail. What if I lose everything?"
```

JSON mode:

```powershell
python scripts/ask_gita.py --mood anxious --text "I've worked on my business for two years and I'm terrified that all of it will fail." --json
```

## Architecture

```text
User
  ↓
Gita Brain understanding
  ↓
Situation + concepts
  ↓
Verse retrieval
  ↓
Evidence pack
  ↓
Grounded prompt
  ↓
Provider adapter
  ├── Gemini
  ├── OpenAI
  └── Groq
  ↓
Answer guard
  ↓
Grounded answer
```
